# COFFEE-SHOP-SALES-ANALYSIS
# ☕ Coffee Shop Sales Analysis
### An Exploratory Data Analysis and Business Intelligence Project Using Microsoft Excel

## 1. Project Overview

The Coffee Shop Sales Analysis project focuses on analysing transactional sales data to understand business performance, identify sales patterns, and uncover meaningful insights that can support better business decisions.

Using Microsoft Excel, this project involves data cleaning, data preparation, exploratory data analysis, and interactive dashboard development. The analysis aims to transform raw sales data into meaningful information through structured reporting and visualisation.

## 2. Business Problem Statement

Coffee shops generate large volumes of transactional data through daily customer purchases. However, raw sales data alone does not provide a clear understanding of business performance.

This project addresses the need to analyse sales trends, evaluate product performance, understand purchasing patterns, and monitor key business indicators.

The objective is to provide a consolidated view of sales performance that helps identify opportunities for business improvement.

## 3. Project Objectives

- Analyse overall sales performance.
- Identify sales trends and patterns.
- Evaluate product-wise sales performance.
- Understand purchasing behaviour.
- Examine sales distribution across available categories and locations.
- Develop an interactive dashboard for effective performance monitoring.
- Generate meaningful business insights from the analysis.

## 4. Tools and Technologies

**Primary Tool:** Microsoft Excel

**Excel Features Used:**
- Data Cleaning and Preparation
- Excel Functions
- Pivot Tables
- Pivot Charts
- Data Visualization
- Interactive Dashboard Development

## 5. Data Preparation and Cleaning

The dataset was reviewed and prepared before performing the analysis.

The preparation process included:
- Reviewing the dataset structure.
- Checking data consistency.
- Identifying potential data quality issues.
- Preparing data for analysis.
- Organising information for effective reporting.

## 6. Exploratory Data Analysis (EDA)

The project explores different aspects of coffee shop sales performance, including:

- Overall sales performance.
- Sales trends over time.
- Product performance.
- Category-wise sales distribution.
- Store-wise sales performance.
- Customer purchasing patterns.

## 7. Key Performance Indicators (KPIs)

The dashboard focuses on monitoring important business performance indicators, including relevant sales and transaction metrics available in the dataset.

## 8. Dashboard and Data Visualization

An Excel dashboard was developed to present the analysis through visual representations of sales data.

The dashboard provides a consolidated view of business performance and makes it easier to identify trends, compare sales performance, and interpret important metrics.

## 9. Key Insights

The analysis is intended to highlight:
- Products contributing significantly to sales.
- Changes in sales performance over time.
- Differences in performance across available business categories.
- Purchasing patterns within the transactional data.
- Potential areas for improving business performance.

## 10. Business Recommendations

The findings can help coffee shop management:
- Identify products with strong sales performance.
- Understand changing sales patterns.
- Improve inventory and product planning.
- Evaluate store-level performance.
- Make informed decisions using sales data.
