# Coffee Shop Sales Analysis – Methodology

## 1. Introduction

This document outlines the methodology followed for the Coffee Shop Sales Analysis project using Microsoft Excel. The project focuses on analysing transactional sales data, evaluating business performance, identifying trends, and presenting insights through an interactive dashboard.

## 2. Dataset Overview

The dataset contains 149,116 transaction records covering the period from January 1, 2023, to June 30, 2023.

The dataset includes the following attributes:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail

## 3. Data Preparation and Validation

The initial dataset was reviewed to understand its structure and identify potential data quality issues.

The validation process included:

- Reviewing column names and data types.
- Checking for missing values.
- Checking transaction IDs for duplicates.
- Verifying date and time values.
- Reviewing numerical fields such as quantity and unit price.

The dataset was converted into an Excel Table named `SalesData` to support structured analysis and data management.

## 4. Data Analysis Approach

Microsoft Excel was used to analyse the transactional data and explore different aspects of sales performance.

The analysis focused on:

- Monthly sales performance.
- Product category contribution.
- Top-performing products.
- Sales distribution across store locations.
- Sales activity by hour.

## 5. Key Performance Indicators

The following KPIs were used to evaluate business performance:

| KPI | Calculation / Measurement |
|---|---|
| Total Sales | Sum of transaction quantity multiplied by unit price |
| Total Orders | Count of transaction IDs |
| Total Quantity Sold | Sum of transaction quantities |
| Top Product Category | Category with the highest sales |

## 6. Dashboard Development

An Excel dashboard was designed to consolidate important business metrics and visualisations.

The dashboard includes:

- KPI cards for sales, orders, quantity sold, and top product category.
- Monthly Sales Trend chart.
- Sales by Product Category chart.
- Top 3 Products by Sales chart.
- Peak Sales Hour chart.
- Sales by Store Location chart.

Interactive slicers were incorporated to allow filtering by:

- Month
- Store Location
- Product Category

## 7. Business Analysis

The dashboard was used to identify patterns in sales performance, product contribution, store-level performance, and hourly sales activity.

The analysis highlighted the leading product category, monthly sales trends, high-performing products, and periods of higher sales activity.

## 8. Tools and Technologies

- Microsoft Excel
- Excel Tables
- Excel Formulas
- Data Analysis
- Data Visualization
- Dashboard Development

## 9. Conclusion

This project demonstrates the use of Microsoft Excel to transform transactional sales data into meaningful business information.

By combining data validation, sales analysis, KPI monitoring, and dashboard visualisation, the project provides a structured view of coffee shop performance and supports informed business decision-making.
